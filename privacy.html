プライバシーポリシー

制定日: 2026年10月12日

「今日の一問」（以下「本アプリ」）は、運営者が自身の TikTok アカウントへ学習動画を送るための個人運用ツールです。本アプリにおける情報の取り扱いを以下のとおり定めます。

1. 取得する情報

  • TikTok との連携時に発行されるアクセストークン・リフレッシュトークン
  • 連携した TikTok アカウントの基本情報（user.info.basic の範囲：Open ID、表示名など）

本アプリは運営者本人のアカウントのみと連携し、それ以外の利用者の個人情報は取得しません。

2. 利用目的

取得した情報は、本アプリが作成した動画を運営者自身の TikTok アカウントの受信箱（下書き）に送信する目的にのみ使用します。

3. 保管方法

トークンは GitHub Actions の暗号化されたシークレットに保管し、公開されることはありません。動画送信の処理中のみ使用し、その他の場所には保存しません。

4. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売することはありません。

5. 連携の解除

TikTok アプリの「設定とプライバシー」→「セキュリティと権限」→「アプリとサービスの権限」から、いつでも本アプリとの連携を解除できます。解除後、保管しているトークンは使用できなくなります。

6. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub の Issues までお寄せください。

7. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点で効力を生じます。

Privacy Policy

Effective date: October 12, 2026

"Kyou no Ichimon" (the "App") is a personal tool used by its operator to send educational videos to the operator's own TikTok account.

Information we collect

Access and refresh tokens issued by TikTok, and basic account information within the user.info.basic scope (such as Open ID and display name) of the operator's own account. The App does not collect information from any other user.

How we use it

Solely to upload videos created by the App to the operator's own TikTok inbox as drafts (video.upload).

Storage

Tokens are stored as encrypted GitHub Actions secrets and are used only while uploading a video.

Sharing

We do not sell or share any information with third parties, except as required by law.

Revoking access

You can revoke the App's access at any time from TikTok: Settings and privacy → Security and permissions → App and services permissions.

Contact

Please contact us via GitHub Issues.
