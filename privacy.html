プライバシーポリシー

制定日: 2026年10月12日 ／ 改定日: 2026年10月13日（YouTube への投稿に関する記載を追加）

「今日の一問」（以下「本アプリ」）は、運営者が自身の TikTok アカウントおよび YouTube チャンネルへ学習動画を投稿するための個人運用ツールです。本アプリにおける情報の取り扱いを以下のとおり定めます。

1. 取得する情報

  • TikTok との連携時に発行されるアクセストークン・リフレッシュトークン、および連携した TikTok アカウントの基本情報（user.info.basic の範囲：Open ID、表示名など）
  • Google（YouTube）との連携時に発行されるアクセストークン・リフレッシュトークン（スコープ youtube.upload のみ）
  • アップロードした YouTube 動画の動画 ID

本アプリは運営者本人のアカウントのみと連携し、それ以外の利用者の個人情報は取得しません。

2. 利用目的

取得した情報は、本アプリが作成した動画を、運営者自身の TikTok アカウントの受信箱（下書き）に送信すること、および運営者自身の YouTube チャンネルにアップロードすることにのみ使用します。

3. YouTube API サービスの利用

本アプリは YouTube API サービスを利用して動画をアップロードします。本アプリを利用することで、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いについては Google プライバシーポリシーをご確認ください。

本アプリが YouTube から取得する情報は、アップロードした動画の ID のみです。チャンネルの他の動画・コメント・分析データなどにはアクセスしません。

4. 保管方法

トークンは GitHub Actions の暗号化されたシークレットに保管し、公開されることはありません。動画送信の処理中のみ使用し、その他の場所には保存しません。動画 ID は重複投稿を避けるための出題履歴としてリポジトリに記録します。

5. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売することはありません。

6. 連携の解除

  • TikTok: アプリの「設定とプライバシー」→「セキュリティと権限」→「アプリとサービスの権限」から解除できます。
  • YouTube（Google）: Google アカウントのセキュリティ設定（サードパーティのアクセス）から、いつでもアクセスを削除できます。

解除後、保管しているトークンは使用できなくなります。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub の Issues までお寄せください。

8. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点で効力を生じます。

Privacy Policy

Effective date: October 12, 2026 / Last updated: October 13, 2026 (added YouTube)

"Kyou no Ichimon" (the "App") is a personal tool used by its operator to publish educational videos to the operator's own TikTok account and YouTube channel.

Information we collect

  • Access and refresh tokens issued by TikTok, and basic account information within the user.info.basic scope (such as Open ID and display name) of the operator's own account.
  • Access and refresh tokens issued by Google for the youtube.upload scope only.
  • The IDs of the videos the App uploads to YouTube.

The App does not collect information from any other user.

How we use it

Solely to upload videos created by the App to the operator's own TikTok inbox as drafts (video.upload) and to the operator's own YouTube channel (videos.insert).

YouTube API Services

The App uses YouTube API Services. By using the App, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data. The only YouTube data the App keeps is the ID of each uploaded video; it does not access other videos, comments, or analytics.

Storage

Tokens are stored as encrypted GitHub Actions secrets and are used only while uploading a video. Uploaded video IDs are kept in the repository's history file to avoid duplicate topics.

Sharing

We do not sell or share any information with third parties, except as required by law.

Revoking access

TikTok: Settings and privacy → Security and permissions → App and services permissions. Google / YouTube: Google security settings (third-party access).

Contact

Please contact us via GitHub Issues.
