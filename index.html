中高生向け「今日の一問」ショート動画

数学・理科の問題と解説を約1分の縦型動画にまとめ、毎日1本お届けする学習コンテンツです。 日付が偶数の日は中学生向け、奇数の日は高校生向けの問題を出題します。

このアプリについて

本アプリは、運営者が自分の TikTok アカウントで「今日の一問」を発信するための個人運用ツールです。 毎日自動で作成した動画を、TikTok の Content Posting API を使って運営者自身の TikTok アカウントの受信箱（下書き）に送ります。 投稿内容の確認と最終的な投稿は、運営者が TikTok アプリ上で行います。

利用する TikTok の権限:

  • user.info.basic — 連携したアカウントの確認
  • video.upload — 作成した動画を受信箱（下書き）に送信

第三者の TikTok アカウントに対して動画を送信・投稿することはありません。

About (English)

"Kyou no Ichimon" (Today's Question) is a personal tool that creates a daily one-minute math/science quiz video for junior and senior high school students in Japan, and sends it to the operator's own TikTok account inbox as a draft via the Content Posting API (video.upload). The operator reviews and publishes each video manually in the TikTok app. The app does not access or post to any other user's account.
